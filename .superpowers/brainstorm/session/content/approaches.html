How should we structure the new dashboard features?

Select the approach you prefer for organizing the Registered Courses list and Detailed Exam Marks.

A

Integrated Sidebar & Performance Expansion (Recommended)

Add a new "Registered Courses" link to the sidebar. Enhance the "Performance" page to show detailed course cards; clicking any card opens a premium modal with a progress-bar breakdown of Test-1, Test-2, Test-3, End-Sem, and Internals.

B

Consolidated Tabbed Dashboard

Keep the sidebar clean. Combine Bunk Meter, Registered Courses, and Performance as top tabs on a single dashboard page. Detailed marks are displayed directly under the Performance tab via accordion dropdowns.

C

Unified Portal Hub (Figma Dashboard style)

Make the main homepage a unified "Academic Hub" showing summary cards for Attendance, Courses, and GPA. Clicking any card navigates to a dedicated page for that section, keeping each interface highly focused.

Pros of Option A

  • Clean navigation using the existing collapsible sidebar pattern.
  • Modals keep the Performance UI clean while showing detailed data when needed.
  • Easiest to implement without breaking existing user routing.

Cons of Option A

  • Sidebar list grows slightly larger (3 items instead of 2).
